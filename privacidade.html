Política de Privacidade: Fato Bizarro Publisher

Última atualização: 1º de novembro de 2026

O Fato Bizarro Publisher é uma ferramenta de uso próprio do canal Fato Bizarro. Ela acessa a conta do YouTube do próprio canal pela YouTube Data API e pela YouTube Analytics API para enviar e agendar vídeos, definir miniaturas, editar títulos e ler estatísticas do canal.

Dados acessados

A ferramenta acessa apenas a conta do YouTube do canal Fato Bizarro, autorizada pelo próprio dono. Não coleta dados de espectadores nem de outros usuários.

Armazenamento

O token de acesso fica salvo apenas no computador do dono do canal. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O uso dos serviços do YouTube também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
